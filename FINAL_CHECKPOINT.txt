The spanchor project is complete and production-ready.

All acceptance criteria met. The system is robust, well-tested, and ready for
deployment to regression-test RAG retrieval pipelines using stable source-document
anchors.

Core principle: separate SOURCE EVIDENCE from RETRIEVAL REPRESENTATION. Gold labels
point at character spans in canonical source documents. Any retriever output 
(spans OR chunk text) is mapped back to those spans and scored.

Central workflow:
  1. Load documents from corpus
  2. Define gold anchors (source spans)
  3. Run retriever (get spans or chunks)
  4. Evaluate against gold labels
  5. Compare runs for regression detection
  6. Report pass/fail for CI
