# SPANCHOR Branding Assets

This directory contains official SPANCHOR branding materials.

## Files

- `spanchor-logo.png` — Primary logo (light backgrounds)
- `spanchor-logo-dark.png` — Dark-mode variant (dark backgrounds)
- `spanchor-icon.png` — Icon for favicons, social preview (64–128px)

## Usage

Refer to [BRANDING.md](../../docs/BRANDING.md) for complete brand guidelines, usage rules, and specifications.

## Color Palette

- **Deep Navy**: #001a4d
- **Bright Blue**: #0066ff
- **Cyan**: #00bfff
- **Gradient**: Cyan to Deep Blue

## Specifications

- **Format**: PNG with transparent background
- **Resolution**: Optimized for both web and print
- **Aspect Ratio**: Maintained across all sizes
- **Minimum Size**: 64px for readability
